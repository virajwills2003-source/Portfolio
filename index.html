STREAM · 4 ENGINEERING NOTES

  1. Splitting flat networks into logical VLANs paired with Variable Length Subnet Masking (VLSM) cuts wasted address space while isolating traffic domains. Verifying connectivity layer-by-layer across the OSI model — physical link state, VLAN trunk tagging, default gateway reachability, and routing tables — turns guesswork into repeatable diagnostics.

  2. Moving a Laravel MVC platform from local development to live Railway hosting highlights the value of strict schema migrations, clean query scoping, and environment-driven database credentials. Keeping validation rules and matching logic separated from Blade templates made debugging production edge cases straightforward.

  3. Encapsulating borrower records, inventory lookups, and lending reports behind dedicated Data Access classes with JDBC PreparedStatements kept the Book Management System secure, maintainable, and easy to extend with fast search and reporting screens.

  4. Building DriveEase from scratch with vanilla HTML5, CSS3, JavaScript, PHP, and MySQL grounded my understanding of the full HTTP request lifecycle — from client-side UX feedback to server-side booking persistence and relational foreign keys.
